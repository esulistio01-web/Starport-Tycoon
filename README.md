# Starport Tycoon

A Java-based spaceport management game developed as a
Basic Programming final project.

## About the Game

Starport Tycoon is a management and strategy game where
players operate a spaceport by deciding which incoming
ships to accept or reject.

Players must balance:
- Money
- Reputation
- Cargo value
- Docking time
- Limited docking slots

The goal is to reach 6,000 Money within 20 days while
keeping the starport's reputation above zero.

## Gameplay

Players encounter different types of ships and must decide
whether accepting or rejecting them is worth the potential
financial and reputational consequences.

## Features

- Ship generation
- Docking management
- Cargo value system
- Docking fee system
- Reputation system
- Limited docking slots
- 20-day game cycle
- Win and lose conditions

- Java
- Object-Oriented Programming
- Basic Programming Concepts
